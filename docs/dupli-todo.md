# Dupli TODO List

> 출처: 2026-10-31 회의 (결제 시스템·라이브 커머스·고객 유입 전략) — 확정 사항 기준
>
> Dupli = 사진·설명·수치만으로 상품을 빠르게 등록하는 최소 입력 툴. 글로벌 팀 사이트와 연동하며, 라이브 방송 중 실시간 상품 등록의 기반이 된다.

## 1. 입력 양식 표준화 (Dupli 스타일 최소 입력 폼)
- [ ] 필수 입력 필드 확정: **사진 / 설명 / 수치(가격·사이즈 등)** 만으로 등록 가능하게 구성
- [ ] 사이즈·컬러를 **변종(Variant)** 으로 입력하는 UI (옆으로 넘겨 추가 입력)
- [ ] 색상 속성 필드 추가 (예: 블랙 선택 시 색상명 표기)
- [ ] **원가(정가) 필드 제거** — 상세 페이지에 원가 노출하지 않음
- [ ] 판매자가 직접 사진을 올리기 쉬운 업로드 UX 최적화
- [ ] 입력 양식 표준 문서화 — **기한: 2026-11-16**

## 2. 글로벌 팀 툴 ↔ Dupli 필드 매핑·동기화
- [ ] Dupli 필드 ↔ 사이트(글로벌 시스템) 상품 필드 매핑표 작성
- [ ] 변종(사이즈/컬러) 데이터 동기화 로직 구현
- [ ] 브랜드/카테고리(프라다, 보테가 등 세분화 메뉴) 매핑
- [ ] 등록 즉시 가격 반영 확인
- [ ] 동기화 테스트 — **기한: 2026-11-22**

## 3. 라이브 실시간 상품 등록 (방송 중 Dupli 활용)
- [ ] 방송 화면 **캡처 → 사진 업로드 → 상품 페이지 자동 생성** 플로우
- [ ] 캡처 후 가격(예: 149,000원) 입력 시 즉시 사이트 게시
- [ ] 사전 수령 자료(사이즈·색상·수량·단가)를 캡처 상품에 바로 연결하는 기능
- [ ] 사전 자료가 없는 현장 신상품(창고 이동 방송 등)도 즉석 등록 가능하게
- [ ] 방송 회차별 **순번(1~8번) 후보 상품 큐** — 사전 설정 / 방송 중 즉석 추가 모두 지원
- [ ] 라이브 중 표시(빨간 점) 및 "라이브 중 판매 상품" 전용 섹션
- [ ] 상품 상세에서 해당 방송 기록(언제 방송했는지)으로 이동 링크
- [ ] 라이브 연동 모듈 재설계 완료 — **기한: 2026-11-21**
